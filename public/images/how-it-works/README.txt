ภาพประกอบ 4 ขั้นตอนในหัวข้อ "เริ่มใช้งานได้ใน 4 ขั้นตอน" บนหน้าแรก
กำหนดที่ `steps` ใน src/config/features.ts และเรนเดอร์ที่ components/marketing/HowItWorks.tsx

เป็นภาพวาดเส้น ไม่ใช่ screenshot ของจริง — สีเขียวแบรนด์บนพื้นเข้ม ให้เข้าชุดกับกราฟในเว็บ
เนื้อหาแต่ละใบต้องตรงกับ imageAlt ที่เขียนไว้ใน config ถ้าเปลี่ยนภาพ ต้องแก้ alt ตามด้วย

ขนาด 1600x1000 (16:10) ทุกใบ ช่องวางจริงกว้างแค่ ~216px (การ์ด 1 ใน 4 คอลัมน์)
จึงเหลือเฟือสำหรับจอ 2x ไม่ต้องทำใหญ่กว่านี้

⚠️ ห้ามทับไฟล์ชื่อเดิมเมื่อเปลี่ยนภาพ — Next.js แคชภาพที่ optimize แล้วตาม URL
ให้ตั้งชื่อใหม่แล้วแก้ path ใน features.ts แทน (เหตุผลเดียวกับ images/features/README.txt)

ไฟล์ PNG ต้นฉบับ (ใบละ ~1.5 MB) อยู่ที่ media-src/how-it-works/ ไม่เข้า git
ย้ายออกจากโฟลเดอร์นี้เมื่อ 30 ส.ค. 2026 เพราะทุกไฟล์ใน public/ ถูกเสิร์ฟให้ใครก็โหลดได้
และจะติดอยู่ในประวัติ git ตลอด ทั้งที่หน้าเว็บใช้แค่ .webp — ดู media-src/README.txt
