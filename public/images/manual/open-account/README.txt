เรนเดอร์ทั้งหน้าจากคู่มือ PDF ฉบับทางการ 15 หน้า (หน้า 2–15) ไม่ได้ดึงรูปย่อย
เพราะแต่ละหน้าออกแบบมาครบในตัว ทั้งลำดับขั้น ป้ายกำกับ และเส้นโยง

    pdftoppm -r 150 -png -f 2 -l 15 <คู่มือ.pdf> out/p
    sharp: resize width 2280 → webp quality 82

ไม่งั้นภาพถูกยืด — อ่านขนาดจริงด้วย  npm run images:sizes manual/open-account

ชื่อไฟล์ตั้งตามขั้นตอน ไม่ใช่เลขหน้า PDF — เปลี่ยนคู่มือแล้วเลขหน้าเลื่อน
