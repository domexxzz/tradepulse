## เข้าเครื่องบอท (คอมเฟิร์ส) ยังไง

- **SSH:** `ssh -i ~/.ssh/id_ed25519 oneye@100.107.33.82` (จาก DomeCB หรือ Mac — key ใส่ไว้แล้วทั้งคู่)
- **default shell ของ SSH = cmd.exe** (ใช้ `%VAR%`, `&` คั่นได้ · `dir`/`type` เร็ว)
- **รัน PowerShell ผ่าน SSH:** `ssh ... "powershell -NoProfile -Command \"...\""` หรือ `-EncodedCommand <base64 UTF-16LE>` กัน quote ซ้อน
- ⚠️ **คำสั่ง PowerShell ยาว/loop ใหญ่ ผ่าน ssh เคยค้างเกิน 120 วิ** — ใช้คำสั่งสั้น ๆ แยกเป็นทีละก้อน
- RDP ผ่าน Tailscale ก็ได้ (`100.107.33.82`) ถ้าอยากเห็นหน้าจอ

## Backend — สภาพเครื่องบอทตอนนี้ + ที่ยังต้องเก็บ

เครื่องรก มีของซ้อน (ทำงานได้แต่ควรเคลียร์ให้เหลือชุดเดียว):
- **botkeeper รัน 2 ตัว** (PID ซ้อน) — autostart แก้เหลือ 1 ทางแล้ว (Registry Run key) **รีบูตทีจะ clean เอง** หรือ kill ให้เหลือ 1 เดี๋ยวนั้น
- **python 3 ตัว** — น่าจะบริดจ์ซ้อนจาก botkeeper ที่เคยซ้อน · ตรวจแล้วเหลือ 1 (บริดจ์เช็กพอร์ต 8787 ก่อนเปิด ไม่เปิดซ้ำอยู่แล้ว)
- **cloudflared 2 ตัว:** (ก) quick tunnel `--url http://127.0.0.1:8787` = ตัวที่ botkeeper คุม เว็บใช้อยู่ (ข) **named tunnel `tunnel run --token-file` = ของ electiction** — ⚠️ **อย่าเพิ่งแตะ** เป็นงานเขา · ถ้า named tunnel นี้ใช้ได้จริง (URL คงที่) อาจเป็นทางเสถียรถาวร แทน quick tunnel + botkeeper ทั้งหมด — คุยกับ electiction ก่อนเปลี่ยน
- **Startup folder ยังมี `Analog Engine.lnk` + `Ollama.lnk` = ของ electiction อย่าแตะ**

**สเต็ปทำ backend ให้เสถียรถาวร (ยังไม่ทำ):**
1. kill botkeeper/python ที่ซ้อน ให้เหลือชุดเดียว (หรือรีบูตคอมเฟิร์สให้ขึ้นสะอาด — ตอนนี้ autostart เหลือ 1 แล้ว ปลอดภัยที่จะรีบูต)
2. คุยกับ electiction เรื่อง named tunnel — ถ้าเสถียรกว่า ย้ายไปใช้แล้วเลิกพึ่ง quick tunnel + botkeeper (ตัด root cause ที่ URL เปลี่ยนทุกรีสตาร์ต)
3. แก้ botkeeper ให้เช็ก `<url>/health` แทนเช็กว่ามี process (กัน tunnel ซอมบี้ — ดู `TRADINGVIEW.md` หัวข้อ "บริดจ์ล่ม")

## หมายเหตุกับดักสำคัญ (จากวันนี้)

- **อย่าให้ผู้ใช้วางคำสั่ง PowerShell ที่มี backtick (`` `r`n ``) เข้าเทอร์มินัลเอง** — เทอร์มินัลกิน backtick กลายเป็น "rn" ทำไฟล์ key พัง 2 รอบ · ใช้ **สคริปต์ดาวน์โหลด** (`gh gist create` → `curl` บนเครื่อง → รัน) แทน
- **สคริปต์ .ps1 บนเครื่องบอทต้อง ASCII ล้วน** — em-dash `—` ทำ string terminator พังบน cp874
- แก้ไฟล์ `authorized_keys` = **admin ใช้ `C:\ProgramData\ssh\administrators_authorized_keys`** (ไม่ใช่ `~\.ssh`) · หนึ่ง key = หนึ่งบรรทัด · สิทธิ์ Administrators+SYSTEM เท่านั้น
