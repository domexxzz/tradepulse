# ทางที่ 2 — รับสิทธิ์ผ่านโบรก Wisdom

ได้อินดิเคเตอร์มีสองทาง

| | ทางที่ 1 | ทางที่ 2 |
|---|---|---|
| ลูกค้าทำอะไร | จ่ายค่าสมาชิก | เปิดพอร์ต Wisdom ผ่านลิงก์ QVX แล้วฝาก $100+ |
| เราได้อะไร | ค่าสมาชิก | ส่วนแบ่งจากโบรก (rebate) |
| สิทธิ์ที่ได้ | ครบ | **ครบเท่าทางที่ 1** — อินดิเคเตอร์ · Telegram · Discord |
| ระยะ | ตามแพ็กเกจ | 1 เดือนตามปฏิทิน ต่อได้ด้วยบัญชีเดิม |

## ลำดับการทำงาน

1. ลูกค้าอ่านข้อมูลที่ `/wisdom` แล้วเปิดบัญชีผ่านลิงก์แนะนำ
2. ล็อกอิน → `/account/wisdom` → ส่งเลขบัญชีเทรด MT5
   (ต้องกรอก TradingView username ก่อน ไม่งั้นส่งไม่ได้)
3. แอดมินได้แจ้งเตือนใน Telegram → เข้า `/admin/wisdom`
4. แอดมินเข้าไปตรวจในระบบ Wisdom เอง — มีบัญชีจริง · สมัครผ่านลิงก์ QVX · ฝากถึงขั้นต่ำ
5. กด **อนุมัติ** → เรียก `activateMembership` ตัวเดียวกับทางจ่ายเงิน (ยอด 0 บาท ช่องทาง `wisdom`)
   บอท TradingView · Telegram · Discord · การหมดอายุ ทำงานเองทั้งหมด

ตรรกะอยู่ที่ `src/lib/broker.ts` · หน้าจออยู่ที่ `src/app/{wisdom,account/wisdom,admin/wisdom}`

## กันให้สิทธิ์ฟรีเกินที่ควร

ทางนี้ไม่มีเงินเข้า จุดที่พลาดแล้วเสียของจริงคือให้สิทธิ์เกิน ป้องกันไว้ 4 ชั้น
แต่ละชั้นมีเทสต์ใน `uat/broker.uat.ts` ที่ยืนยันแล้วว่าถอดออกแล้วเทสต์ล้ม

| ความเสี่ยง | กันยังไง |
|---|---|
| แอดมินกดอนุมัติซ้ำ (ดับเบิลคลิก / สองคนพร้อมกัน) | จองคำขอเป็น `REVIEWING` ด้วย `updateMany` ก่อน — มีแค่คำขอเดียวที่ชนะ |
| คำขอค้างสองอัน อนุมัติทั้งคู่ได้สองเดือน | เช็คช่วงต่ออายุซ้ำตอนอนุมัติ ไม่ใช่แค่ตอนส่ง |
| บัญชีเทรดเดียวรับสิทธิ์ให้หลายคน | `User.brokerAccountKey` เป็น unique ผูกตอนอนุมัติ ฐานข้อมูลเป็นคนตัดสิน |
| กินที่นั่งโปร 300 คนของคนจ่ายเงิน | ช่องทาง `wisdom` ไม่ใช่รายได้ → ยอด 0 → ไม่มีแถว Payment |

**ผูกเลขบัญชีตอนอนุมัติ ไม่ใช่ตอนส่ง** — ถ้าผูกตอนส่ง ใครพิมพ์เลขบัญชีของคนอื่นก่อนก็จองไว้ได้
แล้วเจ้าของตัวจริงส่งคำขอไม่ได้ (ช่องโหว่แบบเดียวกับที่เจอในระบบผูก Discord)

**อนุมัติตายกลางทาง** — ค้าง `REVIEWING` เกิน 5 นาทีกดอนุมัติใหม่ได้ ถ้าเปิดสิทธิ์พลาดจะคืนเป็น `PENDING` เอง

## ตั้งค่า

```bash
vercel env add NEXT_PUBLIC_WISDOM_SIGNUP_URL   # ลิงก์สมัครแบบมีรหัสแนะนำของ QVX
vercel env add NEXT_PUBLIC_WISDOM_GUIDE_URL    # ไม่บังคับ
```

> ⚠️ **ห้ามใส่ลิงก์หน้าแรกของโบรกแทนลิงก์แนะนำ** ลูกค้าที่สมัครผ่านลิงก์ทั่วไปจะไม่นับเป็นบัญชีของ QVX
> ทำครบทุกขั้นแต่สุดท้ายโดนปฏิเสธด้วยเหตุผล "ไม่ได้สมัครผ่านลิงก์ของ QVX"
> ถ้ายังไม่ได้ตั้ง หน้าเว็บจะไม่โชว์ปุ่มสมัครเลย และหน้าแอดมินจะขึ้นแถบเตือน

`NEXT_PUBLIC_*` ถูกฝังตอน build — ตั้งแล้วต้อง redeploy

## ข้อมูลโบรกบนหน้าเว็บ

อยู่ใน `src/config/brokers.ts` เอามาจากคู่มือเปิดบัญชีของน็อต เฉพาะสเปกบัญชีที่เห็นในภาพหน้าจอจริง
(แพลตฟอร์ม · ตลาด · เลเวอเรจ · ฝากขั้นต่ำ)

**ไม่ใส่คะแนนรีวิวหรือจำนวนผู้ใช้ของโบรก** — เป็นตัวเลขของบุคคลที่สามที่เราตรวจไม่ได้
ขึ้นหน้าเว็บเราแล้วกลายเป็นเราเป็นคนอ้าง
