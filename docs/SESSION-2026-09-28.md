## ⛔ เรื่องที่ต้องรู้ก่อนอย่างอื่น: รหัสของ production อ่านกลับไม่ได้

env ทั้ง **34 ตัว** บนโปรเจกต์ Vercel `tradepulse` ถูกตั้งเป็นชนิด **`sensitive`**
ซึ่ง Vercel ออกแบบให้ **เขียนได้อย่างเดียว อ่านกลับไม่ได้ถาวร** — ไม่ว่าจะ token ชนิดไหน
หน้าเว็บ dashboard หรือเจ้าของบัญชีเอง ตรวจแล้วด้วย API:

```bash
# ทุกตัวได้ "type":"sensitive" และ "decrypted":false
curl -H "Authorization: Bearer $VT" \
  "https://api.vercel.com/v9/projects/prj_Ei4cxqF4VNBrA7wu61N4XPghFfah/env?decrypt=true"
```

**ความเสี่ยงที่ตามมา:** ค่าเหล่านี้มีอยู่ที่เดียวในโลกคือในบัญชี Vercel ของโดม
และ **ไม่มีสำเนาที่ไหนเลย** (ตรวจแล้วทั้ง `.env` บนแมคเบสและ shell history — ไม่มี)
ถ้าโปรเจกต์นั้นถูกลบ บัญชีถูกระงับ หรือเข้าถึงไม่ได้ = **กู้ไม่ได้** ต้องไปขอออกใหม่ทุกเจ้า
(Neon, Stripe, Resend, Google, LINE, BotFather)

รายการที่ต้องขอใหม่ถ้าต้องกู้ — ดูหัวข้อ "ถ้าต้องสร้างโปรเจกต์ใหม่" ด้านล่าง

**กฎตั้งแต่นี้ไป:** env ใหม่ให้ตั้งเป็น `encrypted` ไม่ใช่ `sensitive`
ต่างกันแค่ `sensitive` อ่านกลับไม่ได้ ส่วน `encrypted` ยังอ่านได้ด้วย token ระดับบัญชี
สองตัวที่เพิ่มวันนี้ตั้งเป็น `encrypted` แล้ว

## ทำอะไรไปบ้างวันนี้

### 1. เปิดท่อข้อมูลกราฟสด (`MARKET_WEBHOOK_TOKEN`)

ตั้งบน production แล้ว ทดสอบครบทั้งสองทาง:

| ยิงอะไร | ได้ | แปลว่า |
|---|---|---|
| token ผิด | `401 unauthorized` | ด่านรหัสทำงาน |
| token ถูก + ข้อมูลไม่ครบ | `400 invalid_market_snapshot` | ผ่านด่านรหัสแล้ว ตัวตรวจข้อมูลทำงาน |

**ตั้งใจไม่ยิงข้อมูลตัวอย่างเข้าไป** เพราะ `saveSnapshot()` upsert ลงตารางจริง
แล้ว QVX AI จะหยิบไปตอบลูกค้าว่าเป็นราคาจริง — ยืนยันหลังทดสอบว่า `market: []` ยังว่างสะอาด

**ค้าง:** น็อตต้องเปลี่ยน webhook ของ alert อินดิเคเตอร์ QVX AI ไปที่
`https://quantvisionx.com/api/market/snapshot` แล้วใส่ `"token"` ใน body ของ alert
(TradingView ใส่ header เองไม่ได้ token จึงต้องมากับ body — ดู `src/app/api/market/snapshot/route.ts`)

### 2. เปิดช่องรับอีเมลโบรก (`BROKER_MAIL_SECRET`)

`POST /api/broker/email` เปลี่ยนจาก `503 not_configured` → `401` เมื่อส่ง secret ผิด = เปิดใช้งานแล้ว

ติดตั้งบอทบนคอมเบสแล้ว (`ssh tailwin`):

```
C:\QVXAI\mailbot.py    ← จาก scripts/broker/mailbot.py
C:\QVXAI\mail.env      ← SITE + BROKER_MAIL_SECRET เติมให้แล้ว
```

**ค้าง:** ต้องเติม `IMAP_USER` / `IMAP_PASSWORD` ใน `mail.env`
(ใช้ **app password** ของ Gmail ไม่ใช่รหัสผ่านจริง) แล้วค่อยสร้างงานตั้งเวลา
ยังไม่สร้างงานตั้งเวลาให้ เพราะถ้ายังไม่มีรหัส IMAP บอทจะวนล้มทุก 2 นาทีเปล่า ๆ

ทดสอบก่อนตั้งเวลา: `python C:\QVXAI\mailbot.py --interval 0`

### 3. ลบไฟล์ซ้ำ `* 2.*` (12 ไฟล์)

ปัญหาเดิมที่โผล่ซ้ำจาก sync ของ macOS · ตรวจแล้วว่าเหมือนต้นฉบับทุกไบต์ก่อนลบ
ไฟล์พวกนี้ไม่เคยถูก commit แต่ทำ `tsc` พังตอน build ในเครื่อง

## วิธี deploy ด้วย token แบบผูกโปรเจกต์ (`vcp_…`)

token ชนิดนี้ **ใช้กับ Vercel CLI ไม่ได้** — CLI เรียก API ระดับทีมซึ่ง token ไม่มีสิทธิ์:

```
Error: Could not retrieve Project Settings.
```

ถ้าโค้ดบน production ถูกต้องอยู่แล้วและแค่เปลี่ยน env ให้สั่ง rebuild ตัวเดิมผ่าน API แทน:

```bash
# หา deployment ของ production ตัวปัจจุบัน
curl -H "Authorization: Bearer $VT" \
  "https://api.vercel.com/v6/deployments?projectId=prj_Ei4cxqF4VNBrA7wu61N4XPghFfah&target=production&limit=1"

# สั่ง rebuild (ใช้ env ชุดล่าสุดเสมอ)
curl -X POST "https://api.vercel.com/v13/deployments?forceNew=1" \
  -H "Authorization: Bearer $VT" -H "Content-Type: application/json" \
  -d '{"name":"tradepulse","deploymentId":"<dpl_…>","target":"production",
       "project":"prj_Ei4cxqF4VNBrA7wu61N4XPghFfah"}'
```

ถ้าต้อง deploy **โค้ดใหม่** ต้องใช้ token ระดับบัญชี + `vercel deploy --prod --archive=tgz`
จากโฟลเดอร์ที่ export ด้วย `git archive` (อย่า deploy จากโฟลเดอร์งานตรง ๆ — ไฟล์ `* 2.*` จะหลุดไป)

## ค้างอยู่

1. **น็อตเปลี่ยน webhook** ของ alert ไป `/api/market/snapshot` พร้อม token → กราฟสดถึงจะมา
2. **เติม IMAP ใน `C:\QVXAI\mail.env`** บนคอมเบส แล้วตั้งงานตั้งเวลา → บอทอ่านเมลถึงจะเริ่ม
3. **คีย์ Grok** (`OPENAI_API_KEY` + `OPENAI_BASE_URL=https://api.x.ai/v1` + `OPENAI_MODEL`) → AI มีตัวสำรองบนคลาวด์ ตอนนี้คอมเบสดับ = AI ดับตาม
4. **ตั้ง role `PARTNER`** ให้น้อง หลังเขาสมัครบัญชีที่ quantvisionx.com
5. **ซ่อมล็อกอิน Google/LINE** (ดูหัวข้อบั๊กด้านบน)
6. **ปรับตัวอ่านอีเมล** ให้ตรงรูปแบบจริงของ Wisdom เมื่อได้อีเมลฉบับแรก (ดูที่ `BrokerEvent.rawText`)
