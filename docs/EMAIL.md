# ระบบอีเมล (Resend)

ไม่ตั้งค่า = เว็บทำงานปกติทุกอย่าง แค่ไม่มีอีเมลออก
**ยกเว้นเรื่องเดียว: สมาชิกจะรีเซ็ตรหัสผ่านเองไม่ได้** ต้องให้แอดมินช่วย

## อีเมลที่ระบบส่ง

| เมื่อไหร่ | เนื้อหา |
|---|---|
| อนุมัติสลิป / เปิดสิทธิ์ | ใบเสร็จ + วันหมดอายุ + ลิงก์กรอก TradingView username |
| 3 วันก่อนหมดอายุ | เตือนต่ออายุ (ส่งครั้งเดียวต่อรอบบิล) |
| หมดอายุแล้ว | แจ้งว่าปิดสิทธิ์แล้ว + ลิงก์ต่ออายุ |
| กดลืมรหัสผ่าน | ลิงก์ตั้งรหัสผ่านใหม่ (อายุ 60 นาที ใช้ได้ครั้งเดียว) |

เทมเพลตทั้งหมดอยู่ใน `src/lib/email-templates.ts` (HTML inline style ล้วน — โปรแกรมอ่านอีเมลตัด `<style>` ทิ้ง)

## ตั้งค่า

1. สมัคร https://resend.com แล้วเพิ่มโดเมนของคุณในเมนู **Domains**
2. ใส่ DNS record ที่ Resend ให้ (SPF + DKIM) ที่ผู้ให้บริการโดเมน แล้วรอ verify ผ่าน
3. **API Keys** → Create API Key → คัดลอก `re_...`
4. ตั้ง env:

```bash
vercel env add RESEND_API_KEY     # re_...
vercel env add EMAIL_FROM         # TradePulse <no-reply@โดเมนที่ verify แล้ว>
vercel env add EMAIL_REPLY_TO     # (ไม่บังคับ) อีเมลทีมงานจริง ให้ลูกค้ากด reply ถึงได้
```

> `EMAIL_FROM` ต้องใช้โดเมนที่ verify แล้วเท่านั้น ใส่ Gmail/Hotmail ไม่ได้ Resend จะปฏิเสธ

## ทดสอบ

1. สมัครสมาชิกด้วยอีเมลจริงของตัวเอง
2. `/forgot-password` → กรอกอีเมลนั้น → ต้องได้เมลภายในไม่กี่วินาที
3. ดูสถานะการส่งย้อนหลังได้ที่ Resend Dashboard → **Logs**

## เมื่อส่งไม่สำเร็จ

การส่งอีเมลถูกครอบ try/catch ไว้ทั้งหมด — **ไม่มีทางทำให้การเปิดสิทธิ์ล้ม**
ดู log ของ Vercel จะเห็นบรรทัดขึ้นต้นว่า `resend failed:` พร้อมเหตุผลจาก Resend

การเตือนใกล้หมดอายุจะไม่ประทับว่า "เตือนแล้ว" ถ้าส่งไม่ออก
เพราะฉะนั้นเปิดระบบอีเมลทีหลังแล้วรอบถัดไปจะเตือนให้เอง
