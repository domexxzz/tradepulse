# QVX — ตัวเลือกภาพขั้นตอนการเริ่มใช้งาน

มี 3 ชุด ชุดละ 4 ภาพตามลำดับขั้นตอนเดียวกัน ทุกชุดใช้พื้นหลัง black-and-green neon แบบ modern tech landing page: ดำเกือบดำ, glow เขียวเฉพาะจุด, เส้นโค้ง/กริดเทคนิค และพื้นที่มืดสำหรับให้องค์ประกอบเด่น โดยชุด A ถูกนำไปใช้บนหน้าเว็บปัจจุบันแล้ว

| ตัวเลือก | แนวทาง | เหมาะกับ |
|---|---|---|
| A | Line vector | เรียบ สุภาพ โปร่ง และเข้ากับดีไซน์เดิมที่สุด |
| B | Filled geometric | รูปทรงทึบ อ่านง่ายและเด่นเมื่อย่อบนการ์ด |
| C | Precision dashboard | เทคนิค คม และให้อารมณ์เครื่องมือ TradingView |

Preview ชุดล่าสุดที่ใช้พื้นหลัง black-and-green neon:

- [Option A](./option-a-pinterest-neon-preview.png)
- [Option B](./option-b-pinterest-neon-preview.png)
- [Option C](./option-c-pinterest-neon-preview.png)

โฟลเดอร์ `option-a-pinterest-neon`, `option-b-pinterest-neon` และ `option-c-pinterest-neon` คือชุดพร้อมเลือกใช้งานล่าสุด แต่ละโฟลเดอร์มี PNG master และ WebP ขนาด 1600×1000 px โดยเรียงตามขั้นตอน 1–4 เหมือนกันทั้งหมด

เมื่อเลือกชุดอื่น ให้ใช้ไฟล์ WebP จากโฟลเดอร์นั้นแทน path ใน `src/config/features.ts`
