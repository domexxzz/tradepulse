# QVX — ข้อมูลสำหรับดีไซเนอร์

รวมของที่น็อตขอไว้ในโฟลเดอร์นี้ ส่งทั้งโฟลเดอร์ให้ได้เลย

---

## 1. "ภาพพื้นหลังเว็บ" — ไม่มีเป็นไฟล์ภาพ

พื้นหลังเว็บ **ไม่ใช่รูป** แต่วาดสดด้วย CSS + canvas ทุกครั้งที่เปิดหน้า
จึงไม่มีไฟล์ให้ส่ง — แนบภาพที่เรนเดอร์ออกมาแทน ใช้ดูดสี/เทียบโทนได้เลย

| ไฟล์ | คืออะไร |
|---|---|
| `qvx-background-1600x900.png` | พื้นหลังล้วน ๆ ซ่อนเนื้อหาออกหมดแล้ว 1600×900 |
| `qvx-card-frame-closeup.png` | กรอบการ์ดฟีเจอร์ ซูม 3 เท่า เห็นลายที่มีอยู่แล้วชัด ๆ |

### พื้นหลังประกอบจาก 5 ชั้น (บนลงล่าง)

```
1. grain      SVG fractal noise 140×140  opacity .03
2. field      สนามจุดเพอร์สเปกทีฟ วาดด้วย canvas สีเขียวแบรนด์
               มาสก์ radial ให้จางรอบนอก
3. beam       แถบแสงเฉียง 36vw  rgba(110,227,74,.04)  blur 18px  กวาดซ้ายขวา 14 วิ
4. grid       ตาราง 72×72px  rgba(110,227,74,.055)
               perspective(620px) rotateX(61deg)  ไล่จางลงล่าง  ไหลลง 18 วิ
5. base       linear-gradient(180deg, #08100b, #060c08 48%, #050806)
               + radial เขียวจาง 2 จุด (บนกลาง และขวาบน)
```

**ถ้าจะทำลายมาใส่ ขอให้เข้ากับสามข้อนี้**
- เขียวตัวเดียวทั้งเว็บคือ `#6EE34A` — ลายควรใช้เขียวตัวนี้หรือขาว ไม่เอาสีอื่น
- ความทึบของลายพื้นหลังทุกชั้นอยู่ที่ **.03–.055** ห้ามเกินนี้ ไม่งั้นแย่งสายตากับกราฟ
- ไม่เอา glow นีออน — แสงในเว็บนี้ทุกจุด alpha ต่ำกว่า .5 หมด

## 2. ลายในกรอบฟีเจอร์ — มีอยู่แล้ว น็อตทำทับ/แทนได้

ตอนนี้กรอบการ์ดทุกใบใช้ลายนี้ (ดูใน `qvx-card-frame-closeup.png`)

```css
/* ลายเส้นทแยง + ไล่แสงมุมบนซ้าย ซ้อนอยู่ใต้เนื้อหา */
background:
  radial-gradient(125% 85% at 0% 0%, rgba(110,227,74,.05), transparent 58%),
  repeating-linear-gradient(115deg, rgba(255,255,255,.016) 0 1px, transparent 1px 7px);

/* กรอบและแสงของการ์ด */
border: 1px solid  (เขียว 15% ผสมกับ #2b4a32)
box-shadow:
  inset 0 1px 0 rgba(255,255,255,.035),   /* ขอบบนสว่างนิดเดียว */
  0 18px 44px -34px rgba(0,0,0,.95),       /* เงาดำนุ่ม */
  0 0 26px -14px rgba(110,227,74,.10);     /* วงเขียวจาง ไม่ใช่ glow */
```

เส้นทแยง 115° หนา 1px เว้น 6px ที่ **ความทึบ .016** — ถ้าน็อตจะทำลายใหม่
ขอให้อยู่ในระดับความทึบใกล้เคียงกัน (ไม่เกิน .03) และเป็นลายที่ **ไม่มีทิศทางเด่น**
เพราะการ์ดมีทั้งแนวตั้งและแนวนอน

**ส่งกลับมาเป็นอะไรก็ได้:** PNG โปร่งใส (tile ได้ยิ่งดี), SVG, หรือบอกเป็นค่า CSS มาเลย

## 4. ภาพ 4 ขั้นตอน

ตอนนี้การ์ดขั้นตอนยังไม่มีช่องใส่ภาพ มีแค่เลข + หัวข้อ + คำอธิบาย
ถ้าน็อตทำภาพมา ผมจะเพิ่มช่องให้ — ขอเป็นแบบนี้

- **สัดส่วน 16:10** กว้าง 800px ขึ้นไป (การ์ดจริงกว้างประมาณ 280px บนคอม)
- **พื้นหลังโปร่งใส** หรือพื้นสี `#111A14` (พื้นการ์ดขั้นตอน)
- **PNG หรือ WebP** อย่างละ 4 ใบ ตามลำดับนี้

| # | หัวข้อ | คำอธิบายที่ใช้อยู่ |
|---|---|---|
| 1 | สมัครสมาชิก | สร้างบัญชีด้วยอีเมล ใช้เวลาไม่ถึงนาที |
| 2 | เลือกแพ็กเกจ | เลือกระยะเวลาที่ต้องการ ชำระผ่าน PromptPay แล้วแนบสลิป |
| 3 | แจ้ง TradingView Username | กรอกในหน้าบัญชี เพื่อให้ทีมงานเพิ่มสิทธิ์ให้ถูกบัญชี |
| 4 | รับสิทธิ์ใช้งาน | หลังตรวจสอบ เพิ่มอินดิเคเตอร์เข้ากราฟ พร้อมลิงก์เข้ากลุ่ม Telegram |
